# Cómo Contribuir y Desbloquear Acceso a `annoris/solterra-pro`

¡Gracias por tu interés en **SOLTERRA®**!

Este repositorio público ([`annoris/solterra`](https://github.com/annoris/solterra)) comparte la documentación arquitectónica completa, el GIF showcase, los teasers de GSAP 3.13 y la carpeta visual [`solterra/`](./solterra/). El **código fuente completo descargable** (React 19 + Vite 6 + Tailwind CSS 4 + GSAP 3.13 `ScrollSmoother` / `ScrollTrigger` / `SplitText`) se mantiene en el **repositorio privado [`annoris/solterra-pro`](https://github.com/annoris/solterra-pro)** y está reservado exclusivamente para **contribuidores aprobados**.

---

## 🔑 Cómo Obtener Invitación a `annoris/solterra-pro`

Para recibir una invitación oficial de colaborador al repositorio privado [`annoris/solterra-pro`](https://github.com/annoris/solterra-pro), dale una ⭐ a este repo y completa **una** de las siguientes vías:

### Opción 1 — Pull Request de Valor en `annoris/solterra`
Envía un Pull Request en [`https://github.com/annoris/solterra`](https://github.com/annoris/solterra) con aportes útiles para la comunidad:
- Mejoras, diagramas o guías técnicas sobre GSAP `ScrollSmoother`, `SplitText` o `clip-path` en `ARCHITECTURE.md` o `README.md`.
- Traducciones completas de la documentación.
- Guías de optimización de rendimiento o accesibilidad para animaciones basadas en scroll.

### Opción 2 — Issue Técnico / Auditoría de Diseño &amp; Motion
Abre un Issue bien argumentado en [`https://github.com/annoris/solterra/issues`](https://github.com/annoris/solterra/issues) con:
- Propuestas concretas de UX, performance, responsive design o accesibilidad (`prefers-reduced-motion`).
- Ideas de nuevas micro-interacciones o secciones editoriales alineadas a la paleta **Midnight Botanical Pine**.

### Opción 3 — Colaboración Directa o Patrocinio
Si deseas colaborar en diseño, Creative Engineering o patrocinar el proyecto, abre un Issue o contáctanos indicando tu perfil de GitHub (`@tu-usuario`).

---

## 📋 Proceso Paso a Paso (Pull Requests)

1. **Haz Fork** de [`annoris/solterra`](https://github.com/annoris/solterra).
2. **Crea una rama descriptiva**:
   ```bash
   git checkout -b docs/gsap-scrollsmoother-guide
   ```
3. **Aplica tus mejoras** cuidando claridad y formato Markdown.
4. **Abre un Pull Request** en `annoris/solterra` explicando el valor de tu aporte.
5. **Revisión y Acceso**: Una vez que tu PR sea revisado y aceptado (*merged*), recibirás una **invitación directa al repositorio privado [`annoris/solterra-pro`](https://github.com/annoris/solterra-pro)** en tu cuenta de GitHub.

---

## 📜 Reglas de Uso del Código Privado

Al recibir acceso a `annoris/solterra-pro`, te comprometes a:
- No redistribuir, revender ni republicar el código fuente completo de manera pública.
- Utilizar el proyecto para aprendizaje, inspiración o proyectos autorizados respetando los créditos correspondientes.
